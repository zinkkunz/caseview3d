# Walkthrough: Vercel Deployment & 3D Viewer Restoration

## Overview
This document summarizes the resolution of persistent 404 errors, deployment failures, and the restoration of the 3D Viewer in the production environment. We successfully diagnosed and fixed multiple distinct issues blocking the pipeline.

## Problem Summary
1.  **Quota Blocker**: Deployment blocked by Vercel Daily Limit (100/day).
2.  **Webhook Failure**: GitHub webhooks were not triggering Vercel builds after reconnection.
3.  **Security Blocker**: Next.js v15.1.0 was flagged for CVE-2025-66478, instantly rejecting builds.
4.  **Code Errors**: Previously, `fs` module imports in Admin pages caused build failures.
5.  **Corrupted Encoding**: Korean characters in Admin pages were corrupted (Mojibake).

## Solution Steps

### 1. Code Fixes
- **Separated Server Utilities**: Moved `fs`/`path` logic to `lib/server-utils.ts` (Server-Only) to prevent client-side build errors.
- **Restored Encoding**: Used a custom Node.js script to repair corrupted Korean characters in `app/admin/page.tsx` and `app/admin/storage/page.tsx`.
- **Removed BOM**: Cleaned `package.json` and config files of Byte Order Marks.

### 2. Deployment Pipeline Recovery
- **Enforced Node 20**: Added `engines` field to `package.json`.
- **Configured Zero-Config**: Removed conflicting `vercel.json` to rely on Next.js default routing.
- **Added Probes**: Created `/api/healthz`, `/probe`, and `/status.json` for health checking.

### 3. Security Update (Final Fix)
- **Problem**: Build failed instantly with `Vulnerable version of Next.js detected`.
- **Fix**: Updated dependencies to `next@^16.1.1` (Latest) to resolve CVE-2025-66478.
- **Trigger**: Disconnected and Reconnected GitHub Repository in Vercel to force a fresh webhook sync, then pushed an empty commit (`CHORE: Wake up Vercel`) to trigger the build.

## Improvements
- **Robust Health Check**: The system now has a dedicated `/status.json` logic probe.
- **Client-Side Uploads**: Transitioned large file uploads to Client-Presigned URLs (R2) to bypass Serverless function limits.

## Verification
- **Production URL**: `https://www.caseview3d.com`
- **Health Check**: `https://www.caseview3d.com/status.json` (Returns 200 OK)
- **3D Viewer**: User confirmed functional.
